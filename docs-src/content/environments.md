## Pick where and who

Click the chip in the header. Pick an **environment** (where requests go) and a **user** under it (who they’re sent as).

**Default** is wherever the app itself sends its calls, as the user you’re logged in as.

## Add an environment

**+ Add environment** → name, URL and colour.

## Add a user

**+ Add user** under an environment → paste a token. The name fills in from the token. Tick **Add current login** to use the account you’re logged in with.

## Move and copy users

Drag a user onto another environment, or use **⋯ → Move to / Copy to**.

> **Good to know:** a user’s token only goes to its own environment, never anywhere else.
